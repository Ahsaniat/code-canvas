# Support

Thanks for using Code Canvas!

## Where to get help

- **Bug reports and feature requests:** [GitHub Issues](https://github.com/Ahsaniat/code-canvas/issues)
- **Questions:** open an issue and describe what you are trying to do

## Before you file

Please include:

- VS Code version and operating system
- Code Canvas version (Extensions view, or `code --list-extensions --show-versions`)
- Steps to reproduce, and a screenshot if the canvas is involved
- Which languages the project uses (JS/TS, Python, Go, Rust, Java, C#)

## Known limitations

- JavaScript/TypeScript, Python, Go, Rust, Java and C# only
- Bare npm package specifiers are not resolved (project-internal imports are)
- Descriptions are heuristic, not model-generated
